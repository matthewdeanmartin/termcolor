01 / THE PALETTE

Eight colors.
Endless emphasis.

Pick a text color, a background highlight, or layer attributes. Compose the output you need without building ANSI escape codes by hand.

01grey
02red
03green
04yellow
05blue
06magenta
07cyan
08white

Each color also has an on_* highlight. Attributes include bold, underline, reverse, blink, dark, and concealed.

02 / QUICK START

Make your
output pop.

Install the package, import colored to return a string or cprint to print one, and choose the color that fits the message.

More examples in the README ↗
hello.py
# Install the wheel package
pip install termcolor-whl

# Colorize or print directly
from termcolor import colored, cprint

message = colored('Ready', 'green', attrs=['bold'])
print(message)
cprint('Attention!', 'red', attrs=['underline'])

03 / SMALL DETAILS

Fit the terminal
you’re in.

A compact API with predictable output and a straightforward way to switch colors off when plain text is the better fit.

Aa

Return or print

colored() returns a string. cprint() prints it and accepts normal print() options, including file and end.

∅

Plain when needed

Set ANSI_COLORS_DISABLED to a nonempty value and the functions leave text uncolored.

>_

Try the demo

Run python -m termcolor to see colors, highlights, and attributes in your own terminal.

View demo source ↗

This fork does not handle nested color tokens. Actual appearance depends on your terminal’s ANSI support.
