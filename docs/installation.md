# Installation

Install the wheel package into your project's environment:

```bash
python -m pip install --only-binary=:all: termcolor-whl
```

The import name is `termcolor`:

```python
from termcolor import colored, cprint
```

To view its built-in terminal demo, run:

```bash
python -m termcolor
```

The package's declared Python compatibility begins at Python 2.6 and includes Python 3. Current documentation builds use Python 3.14; historical interpreter behavior has not been reverified by this documentation build.
